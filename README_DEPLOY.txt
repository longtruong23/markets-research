GitHub Pages deployment
=======================
1. Create a PUBLIC GitHub repository named: markets-research
2. Upload ALL files/folders in this ZIP to the repository root.
   index.html must be at the top level, not inside another folder.
3. GitHub -> repository -> Settings -> Pages.
4. Under Build and deployment, choose: Deploy from a branch.
5. Branch: main ; Folder: /(root) ; Save.
6. After deployment, GitHub will show the exact live URL under Settings -> Pages.

For a normal project repository, the URL will normally follow:
https://YOUR-GITHUB-USERNAME.github.io/markets-research/

Do NOT paste that pattern into an application until GitHub says the site is live.
Use the exact URL displayed by GitHub Pages.
