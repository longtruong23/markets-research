# Continuity protocol (public reference)

This directory contains a generic, sanitized workflow for resuming long-running engineering work across sessions. It contains no private project state, runtime source, deployment information, credentials, execution logs, or live authority.

Read CONTINUITY_PROTOCOL.md and the empty receipt template. A real installation keeps its current state and artifact archive in a separately controlled private store. This public copy is not a complete project backup and is not automatically synchronized with any running agent.

Documentation only: no workflow, scheduler, hook, service, or broker action is installed by these files.
